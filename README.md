# Task Manager

A React + TypeScript task manager web application with add, delete, and complete task support.

## Features

- Add new tasks with input validation
- Delete tasks
- Mark tasks as completed
- Filter by all, pending, or completed tasks
- Saves tasks in browser local storage

## Getting started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the local URL in your browser.

## Testing

Run the unit tests with:

```bash
npm run test
```

For interactive watch mode:

```bash
npm run test:watch
```

## Copilot customization

- Custom instructions are defined in `.github/copilot-instructions.md`
- A reviewer custom agent is defined in `.github/agents/Reviewer.agent.md`

## Build

```bash
npm run build
```
